# PulseBoard

Uptime monitoring and incident management dashboard for small teams.

> 🚧 Project in active development — built step by step as a portfolio project.

## Tech Stack

- **Frontend:** React, TypeScript, Vite, Tailwind CSS, React Query
- **Backend:** Node.js, TypeScript, Express, Prisma
- **Database:** PostgreSQL
- **Infra:** Docker, Docker Compose, GitHub Actions
